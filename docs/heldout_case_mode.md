# Held-out case challenge — educational interaction

The challenge uses four **original-cohort** rows from the 303-record UCI Extension of Z-Alizadeh Sani dataset. Every displayed probability and label comes from the saved nested outer-fold CSV for that target. The row was outside that target's model-fitting fold. The API never invokes the final model or computes SHAP for these cases. Its saved raw probabilities are not the app's coherence-adjusted live estimates, and target-specific folds can differ.

`scripts/build_heldout_cases.py` verifies each saved label against the source workbook and each fold against `ml/metrics/evaluation.json`. It then selects one CAD true positive, true negative, false positive and false negative, using the median out-of-fold probability within each group. This gives a compact teaching set showing both successes and errors. **These four cases were selected using outcomes; their accuracy is not an estimate of population performance.** They reuse the original cohort and provide no independent or clinical validation.

The packaged `data/processed/heldout_cases.json` contains only four coarse observation bands (age, blood pressure, LDL and echo EF), four target labels and their saved probabilities/folds, plus source/evidence hashes. The case-list response excludes labels and probabilities; the UI calls the public reveal route after a guess. This is an educational interaction, not access control. No names, dates, source row indices, exact ages or full observation vectors are sent. The UCI unit dictionary is incomplete, so the UI labels units as conventional interpretations. The four visible bands cannot explain a prediction from 55 observations.

After a LAD, LCX or RCA reveal, **Inspect vessel on reference heart** selects that artery in the existing 3D atlas and opens a clearly labeled reference-only view. Live prediction cards, their SHAP explanations and their warnings are hidden there, and the atlas receives no saved fold probability as a color value. CAD has no single target vessel, so the challenge does not offer a CAD vessel jump. The return control exits reference-only mode. This is an orientation aid; it does not infer the held-out patient's lesion location or supply a patient-specific heart.

Regenerate with `python scripts/build_heldout_cases.py` after acquiring the original UCI workbook; the deployed app only needs the packaged JSON and saved evaluation files. Verify with `python -m pytest tests/test_heldout_cases.py -q` and `npm test -- --run src/HeldoutChallenge.test.tsx` from `frontend/`. The backend checks evidence hashes on each request and serves both case endpoints with `Cache-Control: no-store`.
