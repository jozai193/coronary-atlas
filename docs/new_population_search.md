# New-population source screen, 9 October 2026

The search targeted a freely downloadable patient-level cohort **independent of the 303-record UCI source**, with non-outcome clinical fields and CAD/LAD/LCX/RCA observations measured against coronary angiography. A record count alone was insufficient: named-vessel outcomes, input timing, license, patient linkage and threshold meaning mattered. We inspected official repositories and primary dataset papers, then downloaded and tested the strongest usable candidate. This is a bounded source screen, not a claim that every online cohort has been exhausted.

| Candidate | Free access / population | Outcome and input match | Decision |
|---|---|---|---|
| [AngioCAD](https://doi.org/10.5281/zenodo.15826856); [paper](https://www.sciencedirect.com/science/article/pii/S0169260726001331) | Zenodo CC BY 4.0; 413 labeled patients, 377 with clinical features, Shahid Chamran Heart Center, Isfahan | Invasive segment bins allow conservative main-vessel labels; 13 sufficiently matched clinical inputs, below the app's 28-of-55 guard | **Executed** as [separate frozen 13-input transport test](angiocad_external_results.md). No 55-input app validation. |
| [CONFIRM](https://data.mendeley.com/datasets/shntp48zv9/1) | Public CC BY 4.0 CCTA registry, 27,125 workbook records | Four clearly matched numeric inputs in prior source-only test; CCTA rather than invasive outcome | [Already evaluated](confirm_external_results.md), poor probability transport; previously inspected, so not a fresh new-population test in this round. |
| [CADICA](https://data.mendeley.com/datasets/p9bpx9ctcv/5) | Free invasive coronary angiography from 42 patients | Lesion/frame annotations lack the required consistent named LAD/LCX/RCA clinical table | Useful for an imaging task, weak for a fair test of this tabular four-target model. |
| [12-lead ECG acute coronary syndrome cohort](https://springernature.figshare.com/articles/dataset/A_large-scale_12-lead_electrocardiogram_dataset_for_acute_coronary_syndrome_prediction_containing_19_955_ECGs/29925314); [paper](https://www.nature.com/articles/s41597-026-07278-0) | Public ECG records from 18,909 patients (19,955 ECGs), CC0 per repository | Age/sex and ECG/ACS outcomes, but no matched 13/55-field pretest table or corresponding >=50% vessel labels | Potential independent ECG product branch, not a valid test of this app's predictor. |
| [Duke ACATHD catalog](https://data.niaid.nih.gov/resources?id=vivli_66629c25-0d61-4f43-a31e-38e155c4054b) | Large catheterization cohort; controlled access request through Vivli | Relevant clinical/vessel fields but no immediately downloadable patient-level file | Future collaboration/request path; unavailable for this bounded free-now experiment. |
| [ARCADE](https://zenodo.org/records/10390295) | Open angiography imaging benchmark | Images and stenosis annotations, not the tabular pretest predictor contract | Different task; would need a separately developed and validated image model. |

The UCI 412 copy and common Kaggle/Mendeley mirrors of the Z-Alizadeh 303 patients were excluded as duplicates, not new populations. The reported 500-record extension appears to contain those same 303 plus 197 further records; a verifiable public patient-level file with the extra records was not found during this search. Further public-data work should focus on an **unused cohort with reviewed acquisition timing and a close 55-field contract**, or on a deliberately new, narrowly scoped product question.

AngioCAD's paper describes the broader angiography collection as non-commercial while its Zenodo record marks the deposited workbooks CC BY 4.0. The research analysis uses the freely downloaded workbooks locally; raw workbooks and media are not included in the source bundle. Confirm redistribution terms before any public raw-data or video packaging.
