# AngioCAD external population experiment: frozen protocol

Fixed on 9 October 2026 **before source-model fitting or AngioCAD outcome scoring**. Workbook headers, category values, missingness, input-range anomalies and endpoint bin counts were inspected to define this mapping. Those are design checks, not performance results. The previous CONFIRM experiment has already been seen; this is a new independent-center cohort, but the endpoint and predictor set differ from the 55-input application. Do not use this result to promote a model into the application.

## Question and population

Can a **fixed 13-input logistic model trained only on the 303-patient UCI Extension of Z-Alizadeh Sani cohort** discriminate and calibrate corresponding angiographic CAD/LAD/LCX/RCA labels in AngioCAD? The source cohort is reported from Shahid Rajaei Cardiovascular Center in Tehran; AngioCAD reports retrospective cases from Shahid Chamran Heart Center in Isfahan. Distinct centers and collection periods support population independence, but anonymous public workbooks cannot prove patient identity separation. A weak exact-match fingerprint check found no match on age, sex, DM, HTN, TG and LDL among complete rows; it is not identity verification.

The AngioCAD label workbook contains 413 unique IDs, the separate clinical feature workbook 377 unique IDs; join one-to-one by ID and evaluate only those with both. The feature workbook repeats stenosis labels. **Do not use its LM/segment columns, Gensini score, angiography series, diagnosis, dominance, LVEF dysfunction, medications or any other non-allowlisted field as a predictor.** No patient IDs or row-level clinical data are published in outputs.

## Inputs and model frozen before scoring

Exactly 13 source fields: `Age`, `Sex`, `BMI`, `DM`, `HTN`, `Current Smoker`, `FBS`, `CR`, `TG`, `LDL`, `HDL`, `WBC`, `PLT`. AngioCAD source mapping in the same order: `Age`, `Sex`, `BMI`, `DM`, `HTN`, `Current Smoker`, `FBS`, `Cr`, `TG`, `LDL`, `HDL`, `leukocytes`, `PLT`. Map `Female` to the source spelling `Fmale`, `Male` to `Male`, and binary 0/1 as source string categories. Missing categorical values remain missing for source-fitted mode imputation. `CR` is creatinine and `WBC` is leukocyte count; the numeric lab units are interpreted as comparable from values and names, but no complete AngioCAD codebook or verification of each measurement's timing was found. This caveat limits interpretation.

Exclude LVEF/EF-TTE because measurement method/timing equivalence is unverified and LVEF is missing in 84/377 rows. Exclude Hyperlipidemia/DLP because definitions are not established as identical, Hgb/HB because one AngioCAD value is 129 against a typical 6.4–17.6 range, and Neut/Lymph because AngioCAD stores fractions while source uses percentages. Exclude Weight and Length to avoid BMI redundancy and substantial missingness. No feature will be added after outcomes are scored.

Use the same simple fixed family for all four targets: numeric training-only median imputation and standardization; categorical training-only most-frequent imputation and one-hot encoding (`handle_unknown=ignore`); logistic regression `C=0.03`, `max_iter=3000`, `random_state=20261007`, no class weighting. Four independent source models fit on all 303 source records. Also compute five-fold stratified source out-of-fold predictions of this **same fixed pipeline**, with no family or threshold search. Store model and source-OOF hashes before external scoring. Do not calibrate, refit, select variables, or tune thresholds on AngioCAD.

## External eligibility and endpoints

For the primary analytic set, require age present and at least 10/13 shared inputs observed. Exclude an external row with any observed numeric input outside these broad data-quality bounds: age 18–100 years, BMI 14–60 kg/m², FBS 40–600, creatinine 0.3–10, TG 20–2000, LDL 5–400, HDL 5–150, WBC 2000–50000, PLT 20–1000 in the source's conventional units. These are prespecified anomaly screens, **not medical reference ranges or source-support truncation**. Before outcome scoring, 363/377 feature rows pass; 6 lack age, 6 have a bound violation and 2 have fewer than 10 inputs. Report exclusions and the source-fitted imputation rates. A secondary sensitivity scores all matched rows **with age present** (371 before outcome exclusions), leaving extreme numeric values unfiltered but still requiring valid binary categories. A separate complete-input sensitivity uses the primary bounds and all 13 fields present.

Take outcome bins only from `AngioCAD_Labels.xlsx`, joined by ID. For LAD, LCX and RCA, use respectively their proximal/mid/distal **main-vessel** segments. `NL` and `1-25` mean negative, and `51-75`, `76-90`, `91-99` and `100` mean positive. If no segment is positive but any is `26-50`, the target is **ambiguous** and excluded for that target. CAD is positive if any of the three main vessels or left main is positive; negative only if all those segments are negative; otherwise ambiguous. The bin `26-50` can contain exactly 50%, so excluding boundary-only cases avoids assigning an unsupported source-compatible binary label. Source outcome labels are supplied binary labels described as at least 50%; AngioCAD bins do not create exact endpoint equivalence. Diagonal, OM, PDA and PLB branches are excluded from the primary vessel mapping; a fixed secondary analysis repeats endpoint construction including those branches. A vessel's ambiguous status does not remove a patient from another vessel's analysis. No observed endpoint is rewritten to match the other endpoints.

Before scoring, the primary-eligible 363 cases have interpretable/ambiguous counts: LAD 228 positive, 94 negative, 41 ambiguous; LCX 90/241/32; RCA 155/171/37; CAD 276/69/18. These counts are recorded for transparency and were not used to tune the model. Diagnose feature-sheet versus label-sheet segment consistency; abort on a material mismatch. Stop if IDs are duplicated, endpoint categories are unknown, a mapped category cannot be justified, or artifacts and source hashes differ from the frozen manifest.

## Metrics and limits

Evaluate all four tasks at fixed 0.5: AUC, Brier, accuracy, sensitivity, specificity, precision, F1, confusion counts, prevalence, mean predicted probability, and source-prevalence constant Brier. Use 1,000 seeded patient-row bootstrap resamples for **descriptive conditional** AUC and Brier 95% intervals. They do not account for source fitting, site clustering or endpoint uncertainty. Save row-level predictions keyed only by a generated row index, the outcome mapping status, aggregate metrics, exclusions, source and destination hashes and software versions. Report primary, branch-inclusive and cohort-filter sensitivities regardless of direction; do not choose a favorable subset as the headline. Since training and external patients were all selected for angiography and AngioCAD includes many acute presentations, this is a spectrum/center transport test, not population screening or prospective clinical validation.
