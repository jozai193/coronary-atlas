# Coronary Atlas

Track A educational research prototype. [Open the interactive demo](https://delicious-she-suggested-laura.trycloudflare.com) · [Narrated demo](https://youtu.be/93zRA3R-Mdo) · [Source, setup and report](https://github.com/jozai193/coronary-atlas).

This free static page embeds the temporary live application. The application runs on the entrant's laptop through a Cloudflare tunnel and remains available only while the server, tunnel and laptop remain running. This is not a managed backend deployment. The video, public source and six-page report remain independently accessible.

Choose A or B for complete recorded development examples. No password or API key is required. Predictions are educational disease-label estimates, not diagnoses, measured narrowing percentages or lesion maps. No independent clinical or broad OCR validation is claimed.

Code MIT. BodyParts3D and the attributed UCI/PTB-XL resources retain source-specific CC BY 4.0 credits in the application and repository. Report images are processed locally in browser memory.

The Python wrapper files document an attempted full runtime deployment. The packaged release loads locally, but this account could not obtain free CPU hosting. Those Python files are not run by this static Space.
