# Cardiofolio

Track A educational research prototype. [Open the interactive demo](https://coronary-atlas-production.up.railway.app) · [Narrated demo](https://youtu.be/opyfTMic1kc) · [Source, setup and report](https://github.com/jozai193/coronary-atlas).

This free static launch page links to the complete Railway-hosted application. A direct launch button avoids unreliable cross-origin embedding. The backend runs independently of the entrant's laptop. Availability depends on the Railway account's remaining credits/plan. The video, public source and six-page report remain independently accessible. Anonymous API and desktop/mobile browser checks passed, including A/B predictions on all three variants, heart controls, explanations, case summaries, local OCR and exports.

Choose A or B for complete recorded development examples. No password or API key is required. Predictions are educational disease-label estimates, not diagnoses, measured narrowing percentages or lesion maps. No independent clinical or broad OCR validation is claimed.

Code MIT. BodyParts3D and the attributed UCI/PTB-XL resources retain source-specific CC BY 4.0 credits in the application and repository. Report images are processed locally in browser memory.

This Space serves index.html and the actual workspace screenshot workspace.png. The Python wrapper files are unused; the complete application is built from the root Dockerfile in the linked public repository. Hosting details and verification receipts accompany the source.
